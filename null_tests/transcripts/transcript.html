        sd_output_id: sounddevice output device index
        sd_input_id: sounddevice input device index
        config: StreamConfig with sample_rate, bit_depth, channels
        blocksize: Callback buffer size in frames

**State variables** (closure over the callback):

**The callback function**:

```python
    def callback(indata, outdata, frames, time_info, status):
        nonlocal file_exhausted, padding_remaining
        
        if status:
            print(f"  Stream status: {status}", file=sys.stderr)
        
        # Always record input
        recording_chunks.append(indata.copy())
        
        # Output: read from file or zero-pad
        if not file_exhausted:
            data = sound_file.read(frames, dtype=dtype)
            n = len(data)
            if n == 0:
                # EOF reached
                file_exhausted = True
                outdata[:] = np.zeros_like(outdata)
                padding_remaining -= frames
            elif n < frames:
                # Partial read (final chunk)
                outdata[:n] = data
                outdata[n:] = 0
                file_exhausted = True
                padding_remaining -= (frames - n)
            else:
                outdata[:] = data
        else:
            # Zero-padding phase
            outdata[:] = 0
            padding_remaining -= frames
            if padding_remaining <= 0:
                finished_event.set()
                raise sd.CallbackStop
    
```

Key design points:
- `indata.copy()` is critical -- sounddevice reuses the buffer. Without `.copy()`, all chunks would point to the same (stale) memory.
- `outdata[:]` assignment is required (in-place write to the pre-allocated buffer; cannot reassign the name).
- `sd.CallbackStop` signals sounddevice to stop the stream cleanly.
- `finished_event` lets the main thread know when to proceed.
- `sound_file.read(frames, dtype=dtype)` does the actual FLAC (or WAV) decode on the audio thread. For WAV, this is a trivial memcpy. For FLAC, this triggers frame decoding.

### 10. Potential Gotchas and Edge Cases

**sf.SoundFile read dtype for FLAC**: When `sf.SoundFile.read(N, dtype='int32')` reads from a FLAC file, libsndfile decodes FLAC frames and returns PCM samples packed into int32. For 24-bit FLAC, the samples are left-justified in the int32 (upper 24 bits used, lower 8 bits zero). This is the same representation used for 24-bit WAV. The bit patterns should be identical if encoding was lossless. This is exactly what we want.

**Blocksize alignment with FLAC frames**: FLAC uses its own block size (typically 4096 samples per frame). The sounddevice callback blocksize (default 2048) is independent. `sf.SoundFile.read()` handles the mismatch internally -- libsndfile buffers decoded FLAC frames and returns the requested number of samples regardless of FLAC frame boundaries. This is transparent to the callback.

**Thread safety of sf.SoundFile.read()**: `sf.SoundFile` is not documented as thread-safe, but since only one thread (the audio callback thread) calls `.read()` on each file object, and the main thread only calls `.close()` after the stream has stopped, there is no contention.

**Recording buffer memory**: Each `indata.copy()` allocates a new array. For a 3-minute stereo file at 96kHz/24-bit (int32), the total recording is ~3*60*96000*2*4 = ~138 MB per pass. The chunk list adds negligible overhead. This is well within reason.

**`sd.Stream` vs `sd.playrec` for channel mapping**: Both accept `input_mapping` and `output_mapping`. The existing backends use `list(range(1, config.channels + 1))` (1-indexed). The `sd.Stream` constructor uses the same convention. No adaptation needed.

## Context

    48→    
    49→    # Use full correlation
    50→    correlation = signal.correlate(rec_float, ref_float, mode='full')
    51→    
    52→    # The peak position relative to where zero-lag would be
    53→    # In 'full' mode, zero-lag is at index len(ref) - 1
    54→    peak_idx = np.argmax(correlation)
    55→    integer_offset = peak_idx - (len(ref_float) - 1)
    56→    
    57→    # Parabolic interpolation for sub-sample refinement
    58→    # Standard formula: δ = (y_plus - y_minus) / (2 * (2*y_peak - y_minus - y_plus))
    59→    if peak_idx > 0 and peak_idx < len(correlation) - 1:
    60→        y_minus = correlation[peak_idx - 1]
    61→        y_peak = correlation[peak_idx]
    62→        y_plus = correlation[peak_idx + 1]
    63→        
    64→        denom = y_minus - 2*y_peak + y_plus
    65→        if abs(denom) > 1e-10:
    66→            # Positive subsample = true peak is to the right of integer peak
    67→            # Negative subsample = true peak is to the left
    68→            subsample = 0.5 * (y_plus - y_minus) / (-denom)
    69→        else:
    70→            subsample = 0.0
    71→    else:
    72→        subsample = 0.0
    73→    
    74→    # Add this generation's sub-sample offset to cumulative total
    75→    new_cumulative = cumulative_subsample + subsample
    76→    
    77→    # When cumulative exceeds ±0.5, adjust integer offset
    78→    # Note: empirically the subsample detection has inverted sign,
    79→    # so we invert the adjustment direction
    80→    adjustment = 0
    81→    if new_cumulative <= -0.5:
    82→        adjustment = +1  # Trim more (audio arriving later than detected)
    83→        new_cumulative += 1.0
    84→    elif new_cumulative >= 0.5:
    85→        adjustment = -1  # Trim less
    86→        new_cumulative -= 1.0
    87→    
    88→    final_offset = max(0, integer_offset + adjustment)
    89→    
    90→    return final_offset, new_cumulative

    93→def extract_aligned_audio(recorded: np.ndarray, offset: int, target_len: int) -> np.ndarray:
    94→    """
    95→    Extract aligned audio from recording starting at offset.
    96→    """
    97→    extracted = recorded[offset:offset + target_len]
    98→    
    99→    # Pad if needed (shouldn't happen with sufficient padding)
   100→    if len(extracted) < target_len:
   101→        pad_len = target_len - len(extracted)
   102→        channels = extracted.shape[1] if extracted.ndim > 1 else 1
   103→        pad = np.zeros((pad_len, channels), dtype=extracted.dtype)
   104→        extracted = np.vstack([extracted, pad])
   105→    
   106→    return extracted

   109→def measure_levels(audio: np.ndarray) -> tuple[float, float]:
   110→    """
   111→    Measure RMS and peak levels of audio.
   112→    
   113→    Returns:
   114→        Tuple of (rms, peak) as linear values
   115→    """
   116→    # Convert to float if needed
   117→    if audio.dtype in (np.int16, np.int32):
   118→        max_val = np.iinfo(audio.dtype).max
   119→        audio_float = audio.astype(np.float64) / max_val
   120→    else:
   121→        audio_float = audio.astype(np.float64)
   122→    
   123→    rms = np.sqrt(np.mean(audio_float ** 2))
   124→    peak = np.max(np.abs(audio_float))
   125→    
   126→    return rms, peak

   129→def apply_gain(audio: np.ndarray, gain: float) -> np.ndarray:
   130→    """
   131→    Apply linear gain to audio, preserving dtype and clipping if needed.
   132→    """
   133→    if audio.dtype in (np.int16, np.int32):
   134→        max_val = np.iinfo(audio.dtype).max
   135→        min_val = np.iinfo(audio.dtype).min
   136→        scaled = audio.astype(np.float64) * gain
   137→        clipped = np.clip(scaled, min_val, max_val)
   138→        return clipped.astype(audio.dtype)
   139→    else:
   140→        return audio * gain

   143→def calibrate_io_gain(backend, config, sample_rate: int, channels: int, dtype) -> float:
   144→    """
   145→    Measure I/O gain by playing pink noise and comparing levels.
   146→    
   147→    Uses bandlimited (20Hz-20kHz) pink noise at -20dBFS for 2 seconds.
   148→    Cross-correlates to align, then compares RMS.
   149→    
   150→    Returns:
   151→        Linear gain factor to compensate for I/O loss
   152→    """
   153→    from scipy import signal as sig
   154→    
   155→    duration = 2.0  # seconds
   156→    num_samples = int(sample_rate * duration)
   157→    
   158→    # Generate pink noise using the Voss-McCartney algorithm
   159→    num_octaves = 16
   160→    pink = np.zeros(num_samples)
   161→    
   162→    for i in range(num_octaves):
   163→        step = 2 ** i
   164→        noise = np.random.randn((num_samples // step) + 1)
   165→        pink += np.repeat(noise, step)[:num_samples]
   166→    
   167→    # Bandlimit to 20Hz-20kHz
   168→    nyquist = sample_rate / 2
   169→    low = 20 / nyquist
   170→    high = min(20000 / nyquist, 0.99)
   171→    sos = sig.butter(4, [low, high], btype='band', output='sos')
   172→    pink = sig.sosfilt(sos, pink)
   173→    
   174→    # Normalize to -20dBFS RMS
   175→    pink = pink / np.sqrt(np.mean(pink ** 2))
   176→    amplitude = 10 ** (-20 / 20)  # -20dBFS
   177→    pink = pink * amplitude
   178→    
   179→    # Convert to target dtype
   180→    if dtype in (np.int16, np.int32):
   181→        max_val = np.iinfo(dtype).max
   182→        test_signal = (pink * max_val).astype(dtype)
   183→    else:
   184→        test_signal = pink.astype(dtype)
   185→    
   186→    # Make stereo if needed
   187→    if channels > 1:
   188→        test_signal = np.column_stack([test_signal] * channels)
   189→    else:
   190→        test_signal = test_signal.reshape(-1, 1)
   191→    
   192→    # Add padding for latency (like generation loop does)
   193→    pad_samples = sample_rate // 2
   194→    padding = np.zeros((pad_samples, channels), dtype=dtype)
   195→    padded_signal = np.vstack([test_signal, padding])
   196→    
   197→    # Play and record
   198→    recorded = backend.playrec(padded_signal, config)
   199→    
   200→    # Use cross-correlation to find alignment (like generation loop)
   201→    offset, _ = find_alignment_offset(test_signal, recorded, sample_rate, 0.0)
   202→    aligned = extract_aligned_audio(recorded, offset, num_samples)
   203→    
   204→    # Measure RMS of both
   205→    ref_rms, _ = measure_levels(test_signal)
   206→    rec_rms, _ = measure_levels(aligned)
   207→    
   208→    if rec_rms > 0:
   209→        gain = ref_rms / rec_rms
   210→        gain_db = 20 * np.log10(gain)
   211→        print(f"  Calibration: ref={20*np.log10(ref_rms):.4f}dBFS, rec={20*np.log10(rec_rms):.4f}dBFS, correction={gain_db:+.4f}dB")
   212→        return gain
   213→    else:
   214→        print(f"  Calibration failed: no signal recorded")
   215→        return 1.0

   253→def run_generation_test(
   254→    source_file: str,
   255→    output_dir: str,
   256→    generations: int,
   257→    milestone_interval: int,
   258→    output_device_idx: int = None,
   259→    input_device_idx: int = None,
   260→    compensate: str = None,
   261→    shared_mode: bool = False,
   262→):
   263→    """
   264→    Run the generation test.
   265→    
   266→    Args:
   267→        source_file: Path to source WAV file
   268→        output_dir: Directory for output files
   269→        generations: Number of generations to run
   270→        milestone_interval: Save a file every N generations (0 = no milestones)
   271→        output_device_idx: Pre-selected output device index
   272→        input_device_idx: Pre-selected input device index
   273→        compensate: Compensation mode - None, 'dynamic' (per-iteration RMS), or 'calibrated' (fixed I/O gain)
   274→        shared_mode: Use WASAPI shared mode instead of exclusive (Windows only, for virtual devices)
   275→    """
   276→    # Create output directory
   277→    output_path = Path(output_dir)
   278→    output_path.mkdir(parents=True, exist_ok=True)
   279→    
   280→    # Get file info first to determine native format
   281→    print(f"\nReading source: {source_file}")
   282→    info = sf.info(source_file)
   283→    
   284→    # Parse bit depth from subtype and determine read dtype
   285→    subtype = info.subtype
   286→    if 'PCM_16' in subtype:
   287→        bit_depth = 16
   288→        read_dtype = 'int16'
   289→    elif 'PCM_24' in subtype:
   290→        bit_depth = 24
   291→        read_dtype = 'int32'  # 24-bit gets packed into int32
   292→    elif 'PCM_32' in subtype:
   293→        bit_depth = 32
   294→        read_dtype = 'int32'
   295→    elif 'FLOAT' in subtype:
   296→        bit_depth = 32
   297→        read_dtype = 'float32'
   298→    else:
   299→        bit_depth = 24
   300→        read_dtype = 'int32'
   301→    
   302→    data, sample_rate = sf.read(source_file, dtype=read_dtype)
   303→    
   304→    channels = data.shape[1] if data.ndim > 1 else 1
   305→    if data.ndim == 1:
   306→        data = data.reshape(-1, 1)
   307→    
   308→    duration = len(data) / sample_rate
   309→    
   310→    print(f"  Sample rate: {sample_rate} Hz")
   311→    print(f"  Bit depth: {bit_depth}")
   312→    print(f"  Channels: {channels}")
   313→    print(f"  Duration: {duration:.2f}s")
   314→    print(f"  Generations: {generations}")
   315→    if milestone_interval > 0:
   316→        print(f"  Milestones: every {milestone_interval} generations")
   317→    
   318→    # Measure reference levels
   319→    ref_rms, ref_peak = measure_levels(data)
   320→    ref_rms_db = 20 * np.log10(ref_rms) if ref_rms > 0 else -np.inf
   321→    ref_peak_db = 20 * np.log10(ref_peak) if ref_peak > 0 else -np.inf
   322→    print(f"  Reference RMS: {ref_rms_db:.4f} dBFS")
   323→    print(f"  Reference Peak: {ref_peak_db:.4f} dBFS")
   324→    if compensate:
   325→        print(f"  Level compensation: {compensate.upper()}")
   326→    
   327→    # List and select devices
   328→    outputs, inputs = list_devices()
   329→    
   330→    out_idx = select_device(outputs, "\nSelect OUTPUT device", output_device_idx)
   331→    in_idx = select_device(inputs, "Select INPUT device", input_device_idx)
   332→    
   333→    output_device = outputs[out_idx]
   334→    input_device = inputs[in_idx]
   335→    
   336→    # Configure stream
   337→    config = StreamConfig(
   338→        sample_rate=sample_rate,
   339→        bit_depth=bit_depth,
   340→        channels=channels,
   341→    )
   342→    
   343→    # Create run metadata
   344→    run_timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
   345→    run_name = f"gen_{Path(source_file).stem}_{run_timestamp}"
   346→    run_dir = output_path / run_name
   347→    run_dir.mkdir(exist_ok=True)
   348→    
   349→    # Save metadata
   350→    meta_file = run_dir / "metadata.txt"
   351→    with open(meta_file, 'w') as f:
   352→        f.write(f"Source: {source_file}\n")
   353→        f.write(f"Sample rate: {sample_rate}\n")
   354→        f.write(f"Bit depth: {bit_depth}\n")
   355→        f.write(f"Channels: {channels}\n")
   356→        f.write(f"Duration: {duration:.2f}s\n")
   357→        f.write(f"Generations: {generations}\n")
   358→        f.write(f"Milestone interval: {milestone_interval}\n")
   359→        f.write(f"Level compensation: {compensate}\n")
   360→        f.write(f"Reference RMS: {ref_rms_db:.4f} dBFS\n")
   361→        f.write(f"Reference Peak: {ref_peak_db:.4f} dBFS\n")
   362→        f.write(f"Output device: {output_device.name}\n")
   363→        f.write(f"Input device: {input_device.name}\n")
   364→        f.write(f"Started: {datetime.now().isoformat()}\n")
   365→    
   366→    # Copy source to run directory
   367→    source_copy = run_dir / f"gen_000_{Path(source_file).stem}.wav"
   368→    sf.write(source_copy, data, sample_rate, subtype=info.subtype)
   369→    print(f"\nSource saved: {source_copy}")
   370→    
   371→    # Run generations
   372→    backend = get_backend()
   373→    backend.shared_mode = shared_mode  # For WASAPI: use shared mode instead of exclusive
   374→    current_data = data.copy()
   375→    
   376→    try:
   377→        print(f"\nConfiguring devices...")
   378→        backend.configure_output(output_device, config)
   379→        backend.configure_input(input_device, config)
   380→        
   381→        # Generous padding to ensure we capture full audio (0.5s should cover any latency)
   382→        pad_samples = sample_rate // 2
   383→        padding = np.zeros((pad_samples, channels), dtype=data.dtype)
   384→        
   385→        # Calibrate I/O gain if using calibrated mode
   386→        io_gain = 1.0
   387→        if compensate == 'calibrated':
   388→            print(f"\nCalibrating I/O gain...")
   389→            io_gain = calibrate_io_gain(backend, config, int(sample_rate), channels, data.dtype)
   390→            with open(meta_file, 'a') as f:
   391→                f.write(f"Calibrated I/O gain: {20*np.log10(io_gain):+.4f} dB\n")
   392→        
   393→        estimated_total = generations * duration
   394→        print(f"\nStarting {generations} generations (estimated time: {estimated_total/60:.1f} minutes)")
   395→        print("-" * 50)
   396→        
   397→        # Log generation header to metadata
   398→        with open(meta_file, 'a') as f:
   399→            f.write(f"\nStarting {generations} generations\n")
   400→            f.write("-" * 50 + "\n")
   401→        
   402→        target_len = len(data)
   403→        cumulative_subsample = 0.0
   404→        
   405→        for gen in range(1, generations + 1):
   406→            # Pad current data with silence at end
   407→            padded_data = np.vstack([current_data, padding])
   408→            
   409→            # Play padded audio and record
   410→            recorded = backend.playrec(padded_data, config)
   411→            
   412→            # Find exact alignment using cross-correlation with sub-sample tracking
   413→            offset, cumulative_subsample = find_alignment_offset(
   414→                current_data, recorded, int(sample_rate), cumulative_subsample
   415→            )
   416→            
   417→            # Extract aligned audio
   418→            aligned = extract_aligned_audio(recorded, offset, target_len)
   419→            
   420→            # Measure levels
   421→            gen_rms, gen_peak = measure_levels(aligned)
   422→            gen_rms_db = 20 * np.log10(gen_rms) if gen_rms > 0 else -np.inf
   423→            gen_peak_db = 20 * np.log10(gen_peak) if gen_peak > 0 else -np.inf
   424→            rms_delta = gen_rms_db - ref_rms_db
   425→            
   426→            # Apply compensation if enabled
   427→            gain_db = 0.0
   428→            if compensate == 'dynamic' and gen_rms > 0:
   429→                # Dynamic: adjust to match original RMS each iteration
   430→                gain = ref_rms / gen_rms
   431→                aligned = apply_gain(aligned, gain)
   432→                gain_db = 20*np.log10(gain)
   433→            elif compensate == 'calibrated':
   434→                # Calibrated: apply fixed I/O gain correction
   435→                aligned = apply_gain(aligned, io_gain)
   436→                gain_db = 20*np.log10(io_gain)
   437→            
   438→            # Check if this is a milestone
   439→            is_milestone = milestone_interval > 0 and gen % milestone_interval == 0
   440→            is_final = gen == generations
   441→            
   442→            # Build console output (compact, <=80 chars)
   443→            if compensate == 'dynamic':
   444→                # In dynamic mode, delta is redundant with gain
   445→                rms_str = f"rms:{gen_rms_db:.2f}dB"
   446→                gain_str = f"  gain:{gain_db:+.2f}"
   447→            elif compensate == 'calibrated':
   448→                # Calibrated mode shows both
   449→                rms_str = f"rms:{gen_rms_db:.2f}dB({rms_delta:+.2f})"
   450→                gain_str = f"  gain:{gain_db:+.2f}"
   451→            else:
   452→                # No compensation: show delta, no gain
   453→                rms_str = f"rms:{gen_rms_db:.2f}dB({rms_delta:+.2f})"
   454→                gain_str = ""
   455→            
   456→            console_line = f"{gen:3d}/{generations}  {rms_str}  pk:{gen_peak_db:.2f}{gain_str}  off:{offset} sub:{cumulative_subsample:+.2f}"
   457→            
   458→            if is_milestone or is_final:
   459→                filename = f"gen_{gen:03d}.wav"
   460→                filepath = run_dir / filename
   461→                sf.write(filepath, aligned, sample_rate, subtype=info.subtype)
   462→                console_line += f"  {filename}"
   463→            
   464→            print(console_line)
   465→            
   466→            # Log to metadata file (full precision)
   467→            if compensate:
   468→                meta_line = f"{gen:3d}/{generations}  rms:{gen_rms_db:.4f}dB({rms_delta:+.4f})  pk:{gen_peak_db:.4f}  gain:{gain_db:+.4f}  off:{offset} sub:{cumulative_subsample:+.4f}"
   469→            else:
   470→                meta_line = f"{gen:3d}/{generations}  rms:{gen_rms_db:.4f}dB({rms_delta:+.4f})  pk:{gen_peak_db:.4f}  off:{offset} sub:{cumulative_subsample:+.4f}"
   471→            if is_milestone or is_final:
   472→                meta_line += f"  {filename}"
   473→            with open(meta_file, 'a') as f:
   474→                f.write(meta_line + "\n")
   475→            
   476→            # Use aligned data as input for next generation
   477→            current_data = aligned
   478→        
   479→        print("-" * 50)
   480→        print(f"\nTest complete! Results saved to: {run_dir}")
   481→        
   482→        # Update metadata with completion
   483→        with open(meta_file, 'a') as f:
   484→            f.write("-" * 50 + "\n")
   485→            f.write(f"Completed: {datetime.now().isoformat()}\n")
   486→    
   487→    except KeyboardInterrupt:
   488→        print(f"\n\nInterrupted at generation {gen}")
   489→        # Save current state
   490→        interrupt_file = run_dir / f"gen_{gen:03d}_interrupted.wav"
   491→        sf.write(interrupt_file, current_data, sample_rate, subtype=info.subtype)
   492→        print(f"Current state saved: {interrupt_file}")
   493→        
   494→        with open(meta_file, 'a') as f:
   495→            f.write("-" * 50 + "\n")
   496→            f.write(f"Interrupted at generation: {gen}\n")
   497→            f.write(f"Interrupted: {datetime.now().isoformat()}\n")
   498→    
   499→    finally:
   500→        backend.release()
   501→    
   502→    return run_dir

def find_alignment_offset(reference: np.ndarray, recorded: np.ndarray, sample_rate: int, cumulative_subsample: float = 0.0) -> tuple[int, float]:
    """
    Find exact sample offset between reference and recorded using cross-correlation
    with sub-sample interpolation.

    Args:
        reference: Original audio played
        recorded: Audio recorded (should be longer due to padding)
        sample_rate: For determining search window
        cumulative_subsample: Running total of sub-sample offsets from previous generations

    Returns:
        Tuple of (integer_offset, new_cumulative_subsample)
    """
    from scipy import signal

    # Use first channel
    ref_mono = reference[:, 0] if reference.ndim > 1 else reference
    rec_mono = recorded[:, 0] if recorded.ndim > 1 else recorded

    # Convert to float for correlation
    ref_float = ref_mono.astype(np.float64)
    rec_float = rec_mono.astype(np.float64)

    # Use full correlation
    correlation = signal.correlate(rec_float, ref_float, mode='full')

    # The peak position relative to where zero-lag would be
    # In 'full' mode, zero-lag is at index len(ref) - 1
    peak_idx = np.argmax(correlation)
    integer_offset = peak_idx - (len(ref_float) - 1)

    # Parabolic interpolation for sub-sample refinement
    # Standard formula: d = (y_plus - y_minus) / (2 * (2*y_peak - y_minus - y_plus))
    if peak_idx > 0 and peak_idx < len(correlation) - 1:
        y_minus = correlation[peak_idx - 1]
        y_peak = correlation[peak_idx]
        y_plus = correlation[peak_idx + 1]

        denom = y_minus - 2*y_peak + y_plus
        if abs(denom) > 1e-10:
            # Positive subsample = true peak is to the right of integer peak
            # Negative subsample = true peak is to the left
            subsample = 0.5 * (y_plus - y_minus) / (-denom)
        else:
            subsample = 0.0
    else:
        subsample = 0.0

    # Add this generation's sub-sample offset to cumulative total
    new_cumulative = cumulative_subsample + subsample

    # When cumulative exceeds +/-0.5, adjust integer offset
    # Note: empirically the subsample detection has inverted sign,
    # so we invert the adjustment direction
    adjustment = 0
    if new_cumulative <= -0.5:
        adjustment = +1  # Trim more (audio arriving later than detected)
        new_cumulative += 1.0
    elif new_cumulative >= 0.5:
        adjustment = -1  # Trim less
        new_cumulative -= 1.0

    final_offset = max(0, integer_offset + adjustment)

    return final_offset, new_cumulative


def extract_aligned_audio(recorded: np.ndarray, offset: int, target_len: int) -> np.ndarray:
    """Extract aligned audio from recording starting at offset."""
    extracted = recorded[offset:offset + target_len]

    # Pad if needed (shouldn't happen with sufficient padding)
    if len(extracted) < target_len:
        pad_len = target_len - len(extracted)
        channels = extracted.shape[1] if extracted.ndim > 1 else 1
        pad = np.zeros((pad_len, channels), dtype=extracted.dtype)
        extracted = np.vstack([extracted, pad])

    return extracted


def measure_levels(audio: np.ndarray) -> tuple[float, float]:
    """
    Measure RMS and peak levels of audio.

    Returns:
        Tuple of (rms, peak) as linear values
    """
    # Convert to float if needed
    if audio.dtype in (np.int16, np.int32):
        max_val = np.iinfo(audio.dtype).max
        audio_float = audio.astype(np.float64) / max_val
    else:
        audio_float = audio.astype(np.float64)

    rms = np.sqrt(np.mean(audio_float ** 2))
    peak = np.max(np.abs(audio_float))

    return rms, peak

def streaming_playrec(
    file_path: str,
    sd_output_id: int,
    sd_input_id: int,
    config: StreamConfig,
    blocksize: int = 2048,
    extra_settings=None,
) -> tuple[np.ndarray, int]:
    """
    Play an audio file via callback-based streaming and record simultaneously.

    The callback reads from sf.SoundFile in chunks, simulating real-world
    progressive decode. For FLAC files, each callback invocation triggers
    on-the-fly FLAC frame decoding via libsndfile.

    Args:
        file_path: Path to WAV or FLAC file
        sd_output_id: sounddevice output device index
        sd_input_id: sounddevice input device index
        config: StreamConfig with sample_rate, bit_depth, channels
        blocksize: Callback buffer size in frames
        extra_settings: Optional sounddevice extra_settings (e.g. WasapiSettings)

    Returns:
        Tuple of (recorded audio array, xrun count)
    """
    dtype = get_sd_dtype(config.bit_depth)
    pad_frames = int(config.sample_rate * 0.5)  # 0.5s padding after EOF

    # Mutable state accessed by callback
    recording_chunks = []
    file_exhausted = False
    padding_remaining = pad_frames
    xrun_count = 0
    finished_event = threading.Event()

    sound_file = sf.SoundFile(file_path)

    def callback(indata, outdata, frames, time_info, status):
        nonlocal file_exhausted, padding_remaining, xrun_count

        if status:
            xrun_count += 1
            print(f"  Stream status: {status}", file=sys.stderr)

        # Always record input
        recording_chunks.append(indata.copy())

        # Output: read from file or zero-pad
        if not file_exhausted:
            data = sound_file.read(frames, dtype=dtype)
            n = len(data)
            if n == 0:
                # EOF reached
                file_exhausted = True
                outdata[:] = 0
                padding_remaining -= frames
            elif n < frames:
                # Partial read (final chunk before EOF)
                if data.ndim == 1:
                    data = data.reshape(-1, 1)
                outdata[:n] = data
                outdata[n:] = 0
                file_exhausted = True
                padding_remaining -= (frames - n)
            else:
                if data.ndim == 1:
                    data = data.reshape(-1, 1)
                outdata[:] = data
        else:
            # Zero-padding phase
            outdata[:] = 0
            padding_remaining -= frames
            if padding_remaining <= 0:
                finished_event.set()
                raise sd.CallbackStop

    try:
        stream = sd.Stream(
            samplerate=int(config.sample_rate),
            blocksize=blocksize,
            device=(sd_input_id, sd_output_id),
            channels=config.channels,
            dtype=dtype,
            callback=callback,
            extra_settings=extra_settings,
        )
        stream.start()
        finished_event.wait()
        stream.stop()
        stream.close()
    finally:
        sound_file.close()

    # Concatenate all recorded chunks
    if recording_chunks:
        return np.concatenate(recording_chunks, axis=0), xrun_count
    else:
        return np.zeros((0, config.channels), dtype=dtype), xrun_count


def compute_null(capture_a: np.ndarray, capture_b: np.ndarray) -> np.ndarray:
    """Subtract two aligned captures in float64, return residual."""
    a = capture_a.astype(np.float64)
    b = capture_b.astype(np.float64)
    return a - b


def measure_null_depth(null_signal: np.ndarray, reference_signal: np.ndarray) -> float:
    """
    Measure null depth in dB relative to reference signal level.

    Returns:
        Null depth in dB (negative number; more negative = deeper null).
    """
    # Normalize integer formats before measuring
    if reference_signal.dtype in (np.int16, np.int32):
        max_val = np.iinfo(reference_signal.dtype).max
        ref_float = reference_signal.astype(np.float64) / max_val
    else:
        ref_float = reference_signal.astype(np.float64)

    ref_rms = np.sqrt(np.mean(ref_float ** 2))
    null_rms = np.sqrt(np.mean(null_signal ** 2))

    # Null signal is already float64 from compute_null; normalize if source was integer
    if reference_signal.dtype in (np.int16, np.int32):
        max_val = np.iinfo(reference_signal.dtype).max
        null_rms = null_rms / max_val

    if null_rms == 0:
        return -np.inf  # Perfect null
    if ref_rms == 0:
        return 0.0  # No signal

    return 20 * np.log10(null_rms / ref_rms)


def parse_bit_depth(subtype: str) -> tuple[int, str]:
    """
    Parse bit depth and read dtype from soundfile subtype string.

    Returns:
        Tuple of (bit_depth, read_dtype)
    """
    if 'PCM_16' in subtype:
        return 16, 'int16'
    elif 'PCM_24' in subtype:
        return 24, 'int32'
    elif 'PCM_32' in subtype:
        return 32, 'int32'
    elif 'FLOAT' in subtype:
        return 32, 'float32'
    else:
        return 24, 'int32'

   181→def streaming_playrec(
   182→    file_path: str,
   183→    sd_output_id: int,
   184→    sd_input_id: int,
   185→    config: StreamConfig,
   186→    blocksize: int = 2048,
   187→    extra_settings=None,
   188→) -> tuple[np.ndarray, int]:
   189→    """
   190→    Play an audio file via callback-based streaming and record simultaneously.
   191→
   192→    The callback reads from sf.SoundFile in chunks, simulating real-world
   193→    progressive decode. For FLAC files, each callback invocation triggers
   194→    on-the-fly FLAC frame decoding via libsndfile.
   195→
   196→    Args:
   197→        file_path: Path to WAV or FLAC file
   198→        sd_output_id: sounddevice output device index
   199→        sd_input_id: sounddevice input device index

   201→        blocksize: Callback buffer size in frames
   202→        extra_settings: Optional sounddevice extra_settings (e.g. WasapiSettings)
   203→
   204→    Returns:
   205→        Tuple of (recorded audio array, xrun count)
   206→    """
   207→    dtype = get_sd_dtype(config.bit_depth)
   208→    pad_frames = int(config.sample_rate * 0.5)  # 0.5s padding after EOF
   209→
   210→    # Mutable state accessed by callback
   211→    recording_chunks = []
   212→    file_exhausted = False
   213→    padding_remaining = pad_frames
   214→    xrun_count = 0
   215→    finished_event = threading.Event()
   216→
   217→    sound_file = sf.SoundFile(file_path)
   218→
   219→    def callback(indata, outdata, frames, time_info, status):
   220→        nonlocal file_exhausted, padding_remaining, xrun_count
   221→
   222→        if status:
   223→            xrun_count += 1
   224→            print(f"  Stream status: {status}", file=sys.stderr)
   225→
   226→        # Always record input
   227→        recording_chunks.append(indata.copy())
   228→
   229→        # Output: read from file or zero-pad
   230→        if not file_exhausted:
   231→            data = sound_file.read(frames, dtype=dtype)
   232→            n = len(data)
   233→            if n == 0:
   234→                # EOF reached
   235→                file_exhausted = True
   236→                outdata[:] = 0
   237→                padding_remaining -= frames
   238→            elif n < frames:
   239→                # Partial read (final chunk before EOF)
   240→                if data.ndim == 1:
   241→                    data = data.reshape(-1, 1)
   242→                outdata[:n] = data
   243→                outdata[n:] = 0
   244→                file_exhausted = True
   245→                padding_remaining -= (frames - n)
   246→            else:
   247→                if data.ndim == 1:
   248→                    data = data.reshape(-1, 1)
   249→                outdata[:] = data
   250→        else:
   251→            # Zero-padding phase
   252→            outdata[:] = 0
   253→            padding_remaining -= frames
   254→            if padding_remaining <= 0:
   255→                finished_event.set()
   256→                raise sd.CallbackStop
   257→
   258→    stream = sd.Stream(
   259→        samplerate=int(config.sample_rate),
   260→        blocksize=blocksize,
   261→        device=(sd_input_id, sd_output_id),
   262→        channels=config.channels,
   263→        dtype=dtype,
   264→        callback=callback,
   265→        extra_settings=extra_settings,
   266→    )
   267→    try:
   268→        stream.start()
   269→        finished_event.wait()
   270→    finally:
   271→        stream.stop()
   272→        stream.close()
   273→        sound_file.close()
   274→
   275→    # Concatenate all recorded chunks
   276→    if recording_chunks:
   277→        return np.concatenate(recording_chunks, axis=0), xrun_count
   278→    else:
   279→        return np.zeros((0, config.channels), dtype=dtype), xrun_count

## Research Summary: Properly Stopping an `sd.Stream` After `CallbackStop`

### 1. The Correct Way to Terminate an `sd.Stream` After `CallbackStop`

The canonical pattern, demonstrated in the official sounddevice examples (`play_file.py`, `play_long_file.py`), is:

**Use `finished_callback` with a `threading.Event` -- never call `stop()`/`close()` proactively from the main thread while audio may still be draining.**

```python
import threading
import sounddevice as sd

event = threading.Event()

def callback(indata, outdata, frames, time, status):
    # ... process audio ...
    if playback_finished:
        outdata[remaining:] = 0
        raise sd.CallbackStop()

stream = sd.Stream(
    samplerate=fs,
    channels=channels,
    callback=callback,
    finished_callback=event.set,  # <-- THIS IS THE KEY
)

with stream:
    event.wait()  # Blocks until finished_callback fires
# 'with' block exits here -> stream.__exit__ calls close()
# This is safe because finished_callback has already fired,
# meaning the stream is inactive and stop()/close() won't block.
```

The `finished_callback` parameter is documented as:

> "User-supplied function which will be called when the stream becomes inactive (i.e. once a call to `stop()` will not block)."

This is critical. The `finished_callback` fires at exactly the moment when it becomes safe to call `stop()` or `close()`. Before that moment, calling either can deadlock.

The `finished_callback` maps directly to PortAudio's `Pa_SetStreamFinishedCallback()`, which is set during stream initialization in the sounddevice source:

```python
# From sounddevice.py _StreamBase.__init__():
if finished_callback:
    def finished_callback_wrapper(_):
        return finished_callback()
    self._finished_callback = _ffi.callback(
        'PaStreamFinishedCallback', finished_callback_wrapper)
    _check(_lib.Pa_SetStreamFinishedCallback(self._ptr,
                                           self._finished_callback))
```

**For your duplex `sd.Stream` specifically:** When `CallbackStop` is raised in the callback, the stream will continue until all pending output buffers have been played. The `finished_callback` will not fire until all that audio has drained. After it fires, the context manager exit (or an explicit `close()`) will work without deadlocking.

### 2. Whether `stream.abort()` Avoids the Deadlock

**Yes, `abort()` should avoid the deadlock in most cases**, but with caveats.

Looking at the sounddevice source:

```python
def stop(self, ignore_errors=True):
    err = _lib.Pa_StopStream(self._ptr)
    ...

def abort(self, ignore_errors=True):
    err = _lib.Pa_AbortStream(self._ptr)
    ...

def close(self, ignore_errors=True):
    err = _lib.Pa_CloseStream(self._ptr)
    ...
```

From the PortAudio documentation:

- **`Pa_StopStream()`** (mapped to `stream.stop()`): "Waits until all pending audio buffers have been played before it returns." This is the one that **blocks/deadlocks** when called while `CallbackStop` is still draining buffers.

- **`Pa_AbortStream()`** (mapped to `stream.abort()`): "Terminates audio processing immediately without waiting for pending buffers to complete." This should return quickly.

- **`Pa_CloseStream()`** (mapped to `stream.close()`): If the stream is still active, this internally calls something equivalent to `abort()` first, then releases resources. However, as documented in the PortAudio mailing list, `Pa_CloseStream` can itself block on macOS because it calls `AudioDeviceStop` internally.

**However**, even `abort()` is not guaranteed deadlock-free on macOS CoreAudio if the audio callback thread is itself blocked. The Mixxx project ([PR #14208](https://github.com/mixxxdj/mixxx/pull/14208)) documented that the real deadlock on CoreAudio occurs when both the callback thread (returning `paComplete`/`paAbort`) and the main thread (calling `Pa_StopStream`) try to terminate the stream concurrently -- they contend on internal CoreAudio mutexes. Their fix was to **wait for the `finished_callback` to fire before calling `Pa_StopStream()`**.

### 3. The `finished_callback` Parameter on `sd.Stream`

**Yes, `finished_callback` exists on `sd.Stream`** (and on all stream types: `InputStream`, `OutputStream`, `RawStream`, etc.).

From the [Stream API docs](https://python-sounddevice.readthedocs.io/en/latest/api/streams.html):

- **Signature:** `finished_callback() -> None` (a zero-argument callable)
- **When it fires:** When the stream becomes inactive -- defined as "once a call to `stop()` will not block"
- **With `CallbackStop`:** For output streams, it will not fire until all generated sample data has been played
- **Thread:** The documentation does not specify which thread it runs on, but it runs on the PortAudio callback thread (the same audio I/O thread), because it is implemented via `Pa_SetStreamFinishedCallback`

**Critical constraint:** You must NOT call `stream.stop()`, `stream.close()`, or any PortAudio API functions from within the `finished_callback` itself. As confirmed in [GitHub issue #78](https://github.com/spatialaudio/python-sounddevice/issues/78):

> "calling stop()/abort() will block until your finished_callback has returned so obviously calling close() inside the callback will cause the thread to hang."

The correct pattern is to have the `finished_callback` signal an event, and have the main thread respond to that signal.

### 4. Known Issues with `CallbackStop` + `stream.stop()`/`stream.close()` on macOS CoreAudio

**Yes, this is a known and well-documented class of bug.**

There are multiple layers to this:

**Layer 1 -- PortAudio level (CoreAudio backend):**
The Mixxx project documented ([PR #14208](https://github.com/mixxxdj/mixxx/pull/14208)) that on macOS CoreAudio, when the callback returns `paComplete` (which is what `CallbackStop` maps to), and the main thread simultaneously calls `Pa_StopStream()`, a deadlock occurs deep inside CoreAudio. Both the audio thread and main thread contend on internal CoreAudio mutexes. Their fix: wait for the stream finished callback before calling `Pa_StopStream()`, validated with 5000+ start/stop cycles without deadlock (vs. failing every ~50 iterations before).

**Layer 2 -- sounddevice level:**
[GitHub issue #78](https://github.com/spatialaudio/python-sounddevice/issues/78) documents that calling `stream.close()` from within the `finished_callback` itself causes a hang, because `close()` internally waits for the callback thread to finish, but the callback thread is the one running `finished_callback`.

**Layer 3 -- PortAudio mailing list (OS X specific):**

The root cause was blocking operations in the stream callback (semaphore waits), which prevented the audio thread from completing, which prevented `AudioDeviceStop` from returning.

### 5. Best Practices -- The Correct Pattern for Your Use Case

Based on all the sources, here is the recommended pattern for a duplex `sd.Stream` with `CallbackStop`:

```python
import threading
import numpy as np
import sounddevice as sd

# Event to signal stream completion
stream_finished = threading.Event()

# Your audio data for playback
play_data = ...  # numpy array
record_data = []  # list to accumulate recorded chunks
current_frame = 0

def callback(indata, outdata, frames, time, status):
    global current_frame
    if status:
        print(f'Stream status: {status}')

    # Record the input
    record_data.append(indata.copy())

    # Play the output
    chunksize = min(len(play_data) - current_frame, frames)
    outdata[:chunksize] = play_data[current_frame:current_frame + chunksize]

    if chunksize < frames:
        outdata[chunksize:] = 0
        raise sd.CallbackStop()  # Signal: playback is done

    current_frame += chunksize

# Create stream with finished_callback
stream = sd.Stream(
    samplerate=fs,
    channels=channels,
    callback=callback,
    finished_callback=stream_finished.set,  # Fires when stream is truly inactive
)

with stream:
    # This blocks until finished_callback fires.
    # At that point, all audio has drained and the stream is inactive.
    stream_finished.wait()

# The 'with' block's __exit__ calls stream.close().
# This is safe because finished_callback already fired,
# meaning the stream is inactive.

# Process recorded data
recorded = np.concatenate(record_data)
```

**Key rules:**

1. **Never call `stream.stop()` from the main thread while `CallbackStop` is draining buffers.** This is the deadlock. `Pa_StopStream` waits for buffers to drain, but if the audio thread is also trying to drain them via `paComplete`, you get contention on CoreAudio mutexes.

2. **Use `finished_callback=event.set` and `event.wait()`.** This is the official, documented pattern. The `finished_callback` fires when the stream is truly inactive -- at that point `stop()` and `close()` will not block.

3. **Never call `stop()`/`close()`/`abort()` from inside the `finished_callback` or the stream `callback`.** These run on the audio thread; calling PortAudio API functions from within will deadlock.

4. **If you need to force-stop (e.g., timeout), use `stream.abort()` rather than `stream.stop()`.** `abort()` calls `Pa_AbortStream` which does not wait for buffers to drain. But even this should ideally be done after confirming the stream is no longer in the middle of a callback invocation.

5. **The `with stream:` context manager is your friend.** It calls `start()` on entry and `close()` on exit. Combined with `event.wait()` inside the `with` block, the `close()` only happens after the stream is already inactive.

6. **If you need a timeout on the wait** (to handle the case where audio never finishes), use `event.wait(timeout=some_seconds)` and then call `stream.abort()` if the timeout expires:

```python
with stream:
    if not stream_finished.wait(timeout=expected_duration + 5.0):
        # Timed out -- force abort
        stream.abort()
```
